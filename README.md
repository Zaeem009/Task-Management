# Task-Management
Task Management Application is a web application used to create, update, and track tasks. It provides secure user authentication and authorization. Users can perform CRUD operations such as adding, editing, and deleting tasks. The application is responsive and works smoothly on both web and mobile devices.
A fully interactive Task Management Application built to spec.

Features implemented:

1.CRUD operations — add tasks (with the "+ Add task" button), mark complete/incomplete (click the circle), and delete (trash icon on hover)
2.Priority tagging — High, Medium, Low with color-coded badges
3.Filtering — filter by priority or status using the chips
4.Multiple views — All tasks, Today, Upcoming, Completed via the sidebar
5.Stats dashboard — live counters for total, in-progress, completed, and a progress bar
6.Categories — Engineering, Design, Marketing, Research
7.Due dates — with overdue highlighting in red
8.Responsive layout — sidebar + main content panel

Note: Click the circles to complete tasks, hover a task to delete it, or hit "+ Add task" to create a new one with priority, category, and due date.
